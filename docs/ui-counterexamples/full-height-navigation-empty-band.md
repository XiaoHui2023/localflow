# 反例：内容很少却把导航画满整个视口

## 问题

只有六个入口时，全高背景和贯穿视口的分隔线把下方空白误表现成一个有功能的区域。空白没有承载滚动、底部动作、账号信息或状态，因此删除它不损失理解与操作。

## 处理

布局仍保留稳定的左侧轨道，避免页面内容横向跳动；可见导航容器改为左上角按内容收缩的卡片。六个图标加文字入口、当前态、方向键顺序和至少 40px 的目标高度保持不变。

## 不应机械套用

如果侧栏拥有独立滚动、固定底部动作、跨区分组或需要以整栏背景表达结构，全高可以有明确所有者。此反例只针对“高度仅用于填满”的空带。

## 回归检查

- 1440×900 下可见导航高度不超过 300px。
- 六个入口目标高度均不小于 40px。
- 390px 宽度无横向溢出，文字仍可辨认。
- 删除容器下方空白后，内容列位置保持稳定。
