# 反例：把常用对象操作塞进“更多”菜单

## 失败形态

用户已经选中一个配置，却必须先点击“文件操作”，再点击“重命名”或“删除”。第一下既不选择对象、不输入数据、不确认风险，也不完成动作，只是界面中转。

## 删除测试

把重命名和删除作为所选对象的直接图标动作后：重命名从两次点击降为一次；删除从“菜单 + 删除 + 确认”降为“删除 + 确认”。删除确认仍保留，因为它承担不可逆风险；通用菜单没有独立职责，应删除。

## 验收

- 从对象已选中开始分别统计点击、提交、模式切换和页面往返。
- 常用动作的界面税为零。
- 图标具有可访问名称、悬浮提示、键盘焦点和禁用状态。
- 窄屏空间不足时可以改用短文本或对象级动作区，但不能以“整洁”为由恢复无语义菜单。
