## 交互质量预算

交互质量不是主观口号。浏览器门禁固定检查以下用户可观察结果：

- 可运行配置从资源树到可填写运行参数只需一次激活，不要求再切换“使用”模式。
- 无效配置从资源树到错误详情只需一次激活；资源树只给简洁状态提示，详细错误在打开后就地出现。
- 成功反馈位于固定通知层且在 5 秒内自动消失；出现前后资源树、工具栏和内容区的 `x/y/width/height` 完全不变。错误反馈保留，直到用户修正或切换上下文。
- 使用态显示插件合同返回的只读解析值；路径/命令错误同时具备非颜色图标、鼠标悬浮与键盘聚焦说明。打开、保存、外部同步和相关输入变化都会有界重查。
- 不设置手动刷新、手动扫描或重复的配置状态标题；文件变化和任务状态由自动同步负责。
- 状态不能只靠颜色表达：文件名保持中性，普通参数、共享片段、可运行配置和错误配置使用不同图标、可访问名称和行内诊断。
- 主导航只有任务、终端、设置；运行在任务页内以一个 disclosure 按钮开合，插件与 API 说明只存在于项目文档。
- 运行面板默认折叠；1440px 展开后与任务并排，1100px 以下置于任务上方，390px 内部资源树与配置面板上下排列。展开/收起只需一次操作，必须保留当前标签页的文件、模式和输入，并在全部三档视口保持零页面横向溢出。
- 运行操作使用可访问的正方形 Play 图标按钮；编辑使用短标签“编辑”，界面不重复配置扩展名。
- 设置使用一个统一列表，标签与控件在同一基线；桌面和 390px 视口的时间校准不得无故断成两行。
- 网页退出从设置页只需一次直接点击和一次必要确认，界面税为零。确认框默认聚焦取消，Esc 恢复触发焦点，Portal 模态层不改变底层几何，确认期间只允许一次请求。
- 390px 视口无水平溢出，axe serious/critical 问题为 0。此门禁不外推到未测试的辅助技术、语言和任意视口。
- 有效配置的使用态只允许出现插件 `run_fields`；配置专属字段不得渗入日常运行表面。
- Case 网格初始次数必须全部为零；框选只改变临时作用域，不得隐式增加运行次数。悬浮滚轮调整单项，组内增量和固定值编辑同步到全部框选项；点击组件外取消作用域，不显示独立批量工具条。零次项不显示次数，随机种子默认留空；正式入队后任务详情必须直接显示“随机种子”，且与不可变命令实际使用的值一致。
- 从运行页切换到其它导航再返回时，所选文件、编辑/运行模式和未提交的运行参数保持不变。
- 缺公共字段、字段类型错误和语法错误必须分别产生可见诊断，且运行 API 全部 fail closed 为 422。
- 一级按钮高度为 34–38px，资源树图标按钮为 32px；异常尺寸会使 Edge 几何断言失败。
- 已打开页面必须在构建修订变化后 8 秒内产生新主文档导航；HTML 与 API 的 `Cache-Control` 必须为 `no-store`。
- 普通任务行首点数量必须为 0；新完成任务恰有一个红点。聚焦、脚本展开和刷新保持红点，只有真实鼠标悬浮后消失。
- 历史任务与带插件计算值的详情分别在 1440px、760px、390px 验证：末项至详情底边不超过 12px，任务卡片不存在行与详情之外的高度。仅验证桌面宽度不构成通过。
- 同标签集同名队列无条件合并为 `×N`；总队列第 20/21 项形成阈值对照，超过 20 才出现按完整标签集折叠，无标签项不折叠。

完整命令、环境、目标探针、浏览器截图、故障样本和工具兼容性说明见 `quality/evidence/2026-08-25-final.md`。

发布兼容性是硬门：PyInstaller 与 StaticX 必须在同一个 Ubuntu 16.04 基线内完成，CI 随后用 QEMU 在 `qemu64`、`core2duo`、`Opteron_G1` 三种无 AVX 的早期 x86-64 模型上执行最终制品的零参数启动探针。新宿主机原生 smoke 不能替代该门；只验证主体而让下游重新捆绑加载器也不能通过。
本次逃逸、成熟实现对照、失败迭代与声明边界记录在 `quality/evidence/2026-08-26-linux-isa-escape.md`。

## 本体资源预算

预算唯一来源是 `quality/resource-budgets.json`。服务样本先从 SQLite 证明活跃任务为零，再聚合控制器及其服务子进程；页面样本在完整运行工作台空闲六秒，使用 Edge DevTools 的累计任务时间差、JS 堆和 DOM 计数，同时统计 fetch/XHR 与存活 WebSocket。浏览器共享外壳不归属单个网页，因此不冒充 LocalFlow 页面内存；页面可归属开销由渲染进程指标表达。收据超限、缺字段、契约不一致或活跃任务非零均由 `tools/check_quality.py` 拒绝，测试还把堆值篡改为超限值证明判定器能抓住失败。

## 操作次数预算

从“对象已选中”开始计数。重命名需要一次直接点击后进入名称输入；删除需要一次直接点击和一次不可逆确认。打开通用“文件操作”菜单属于界面税，目标为零。任务值复制为一次点击，终端是独立能力所以允许一次一级导航，但任务展开区不得再要求“详情→终端”的二级往返。

## 发布判定

当前核心服务、Ubuntu systemd 执行、权限、生产前端构建与 Edge 浏览器交互均有直接证据。浏览器门禁每轮先构建当前源码，再验证匿名设置页秘钥登录、错误反馈、登录控件消失、持久会话、配置树 CRUD、配置内使用、任务原位详情、xterm、axe 与 390px。服务测试另行验证回环不自动授权、服务重启后会话保持、秘钥变更撤销旧会话和 POSIX 权限。

局域网入口门禁验证默认 wildcard 监听只展示可复制的首选私有 IPv4、真实 Edge 经该地址访问、显式回环保持原样、可选 TLS 必须成对且代理 CIDR 必须有效。HTTP 仅声明覆盖可信离线局域网，不扩张为具备传输机密性。

任何自主学习或工具接入失败都必须在最终报告和证据文件中写明学习目标、可验证错误、影响、替代方案与恢复条件。
