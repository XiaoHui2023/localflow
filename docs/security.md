# LocalFlow 安全设计

## 边界

客户端地址不代表用户身份，`127.0.0.1` 也不会自动成为管理员。所有未登录网页都按 `anonymous_access` 投影；默认只能读取去敏任务摘要。配置、运行、终端交互、中断和校时等操作必须先在设置页完成秘钥登录。随机端口只减少偶然冲突，不是安全边界。

| 能力 | 摘要匿名 | 完整只读 | 管理员会话 | HMAC 客户端 |
| --- | --- | --- | --- | --- |
| 任务摘要 | 是 | 是 | 是 | 是 |
| 完整详情与日志 | 否 | 是 | 是 | 是 |
| 提交任务或批次 | 否 | 否 | 是 | 是 |
| HTTP 终端输入、中断、确认 | 否 | 否 | 是 | 是 |
| 配置、变量与插件发现 | 否 | 否 | 是 | 是 |
| 浏览器 WebSocket、校时、受保护 OpenAPI | 否 | 只读 WebSocket | 是 | 否 |

隐藏网页按钮不是授权依据；每个 HTTP 和 WebSocket 入口独立检查身份。

## 浏览器管理员会话

用户从 `secrets/web-admin-key` 复制秘钥，在设置页输入一次。秘钥只存在于本次登录请求体，不进入 URL、服务器响应、日志、cookie 或浏览器持久存储。服务端签发由该秘钥 HMAC 签名的 `HttpOnly; SameSite=Strict` cookie；HTTPS 时同时设置 `Secure`。cookie 采用长有效期并在页面恢复会话时续期，因此浏览器刷新和服务重启后仍保持登录；修改网页管理员秘钥会立即使全部旧签名失效。

响应正文只返回从签名会话派生的 CSRF 令牌，网页仅保存在内存中。cookie 写操作要求精确匹配当前 scheme 与 Host 的 `Origin`，并用常量时间比较 `X-CSRF-Token`。WebSocket 管理身份要求同源 Origin；匿名完整只读连接即使发送 `input` 或 `resize` 也会被拒绝。

## 程序请求签名

程序先取得 30 秒 challenge，然后使用当前 `secrets/api-key` 对方法、含查询路径、正文 SHA-256、代次、Unix 秒和随机数进行 HMAC-SHA-256。随机数绑定签发时的密钥代次，并在第一次验证尝试时消费，不能重放。

只读请求也必须签名精确的查询字符串。请求一旦携带任一签名头却校验失败，服务返回 `403`，不会把它当匿名请求继续并返回较弱投影，避免程序误把认证失败当成成功。

任务进入终态后 API 密钥原子替换并进入下一代。内存只保留上一代密钥 30 秒，且只能配合轮换前签发的随机数；轮换后签发的新随机数不能降级使用旧密钥。调用方仍应在每次请求前重新读取磁盘文件。

## 密钥文件

`secrets` 必须是服务用户拥有的真实目录且不能向组或其他用户开放；两个密钥必须是同一用户拥有、硬链接数为 1 的普通非符号链接文件，且不能含任何组/其他用户权限。新目录使用 `0700`，新密钥使用 `0600`。POSIX 启动检查失败时服务拒绝启动，而不是降级为不安全写接口。

API 密钥不进入浏览器存储、任务请求、任务环境或事件数据。严格部署使用专用非 root `localflow` 用户，并保护运行根目录不被其他账号读取。

`web-admin-key` 只用于浏览器登录，`api-key` 只用于程序 HMAC 调用，两者互不替代。服务启动不会打印任何秘钥。旧版本的 `secrets/admin-bootstrap` 会在首次升级启动时原子迁移为 `web-admin-key`，值保持不变。

## 网络和命令

默认绑定 `0.0.0.0:0`，启动后选择首选局域网 IPv4 作为展示地址；终端与权限为 `0600` 的 `runtime/port` 都只显示可访问的 `IP:端口`，不显示 `0.0.0.0`。改为 `127.0.0.1` 可限制为服务器本机访问。

网页登录只能阻止不知道秘钥的人操作，HTTP 无法抵御局域网抓包或中间人。直接 HTTP 只适用于受信任的离线局域网；其他网络必须配置成对的 TLS 证书与私钥。`trusted_proxies` 只在实际经过反向代理时配置，Uvicorn 只接受这些 CIDR 的转发头。

任务命令始终以参数数组交给执行器。需要管道或重定向时，用户必须在数组中显式调用 `bash -lc`，因此 shell 风险在任务详情中可见。用户插件是受信任本地代码，没有 Python 沙箱。

HTTP 响应启用 `nosniff`、`no-referrer` 和只允许本地脚本/连接的 CSP。终端块和输入均限制为 64 KiB，尺寸限制为 2–1000 行列；WebSocket 的 await 发送提供传输背压。当前版本未实现按身份的请求速率限制，部署在非回环网络时应由受信任反向代理补充连接数和速率上限。
