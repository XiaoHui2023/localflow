# 终态任务详情数组与时间标签

- 发现：运行配置的 `code-list` 已逐项渲染，但通用任务详情仍把对象（包括数组）交给 `JSON.stringify`，所以终态数组退化为单行。这是投影视图复用不完整，而不是插件数据丢失。
- 修复：任务详情增加统一列表所有者；一个数组对应一个带标签的 `role=list`，每个元素拥有独立 `role=listitem`、完整宽度复制面和复制反馈。自定义文本仍保持无冗余标题的既有专用语义。
- 一致性：开始时间移除孤立时钟图标，改为纯文字“开始时间”；短时间继续可见，完整时间继续保留在 `datetime` 与 `title`。
- 直接门禁：Edge 通过任务 API 创建含两个数组元素的任务，等待其真实完成并展开详情；断言恰有两行、逐项内容准确、每个 row/value 与 owner 宽度误差不超过 1px，同时断言时间标签精确且无 SVG。固定 Chrome 84、Firefox 78 继续覆盖构建后的详情兼容性。
