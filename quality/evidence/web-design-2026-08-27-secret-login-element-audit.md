# 设置页秘钥登录元素审计

目标路径只有一次：设置 → 输入秘钥 → 登录。

| 元素 | 保留理由 | 移除后的影响 |
| --- | --- | --- |
| 主题切换 | 未登录浏览器也需要保持显示习惯 | 无法设置和记忆主题 |
| “秘钥登录”标签 | 说明输入用途 | 密码框语义不清 |
| 密码输入框 | 唯一认证材料入口 | 无法登录 |
| 登录按钮 | 明确提交且支持键盘 Enter | 无法可靠提交 |
| 条件错误文本 | 错误秘钥需要就地反馈 | 用户无法判断失败原因 |

未保留：秘钥文件路径说明、登录状态卡片、摘要、版本、帮助文字、成功弹窗和退出按钮。文件路径与安全规则只进入项目文档；成功由登录行消失和管理员功能出现表达。
