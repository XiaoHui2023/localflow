# Round 7 元素删除审计

| 元素 | 删除后果 | 判定 |
| --- | --- | --- |
| 六个导航文字 | 纯图标难以直接识别 | 保留 |
| 导航下方全高背景 | 不影响定位、操作或结构 | 删除 |
| 时间卡装饰图标 | 时间本身已是首要识别对象 | 删除 |
| “服务器当前时间”说明 | live timer 的位置与内容已表达 | 删除 |
| “时间校准”标签 | 输入目的会不清楚 | 保留并作为控件标签 |
| 秒级变化的播报 | 会持续打断辅助技术 | 禁止，`aria-live=off` |
| 配置诊断徽标 | 决定能否使用及错误入口 | 保留 |
| 普通配置“普通配置”徽标 | 没有操作差异，增加噪声 | 不显示 |
| 插件二次选择器 | 与顶层 `plugin` 冲突 | 仅新建时用于生成文件；打开后不显示 |
