# 第十轮元素删减审计

判断问题：用户完成任务是否需要它；删除后是否损害理解、操作、反馈或恢复。

| 原元素 | 决策 | 最终表达 | 验证 |
|---|---|---|---|
| 导航“配置” | 重命名 | 第二项“运行” | Edge 导航顺序断言 |
| 插件页 | 删除 | 插件说明留在项目文档 | DOM 中目的地不存在 |
| API 页 | 删除 | API 使用与密钥说明留在项目文档 | DOM 中目的地不存在 |
| “修改 YAML” | 精简 | “编辑” | 按钮文本断言 |
| “加入队列”文字按钮 | 精简 | 播放图标 | 图标按钮、方形几何、可访问名称断言 |
| 文件扩展名 | 隐藏 | 文件名主体 | 资源树和标题不出现支持格式扩展名 |
| 文件名状态色 | 删除 | 中性文件名 | 三类文件名计算色一致 |
| 普通/任务/错误文字徽标 | 删除 | 普通文件、任务文件、红色错误图标 | 图标及 `aria-label` 断言 |
| 插件名徽标 | 删除 | 运行表单只显示本次可输入字段 | 字段渐进披露断言 |
| 设置卡片图标与重复标题 | 删除 | 单面板、两条对齐设置 | 行中心线与单一时间控件断言 |

## 反向检查

- 图标按钮没有删除机器可读名称；鼠标悬停仍可看到原生提示。
- 错误没有只靠红色表达；错误文件图标形状不同，打开后显示具体诊断。
- 隐藏扩展名不改变实际文件路径；创建和重命名继续保留原格式。
- 删除前端文档页不删除任何项目文档或后端 API。
