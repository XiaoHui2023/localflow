# 渐进式网页设计迭代

## 基线

- 宽屏与窄屏基线已在改版前目视检查；旧截图由新版四张签名截图取代，不混入当前浏览器收据。
- 优点：任务信息和详情同时可见；状态不只依赖颜色。
- 缺点：默认深色；品牌、角色、筛选、刷新与空分区占据第一视口；配置页仍用相同暗色；无 API 文档页。
- 硬失败：默认主题、元素关注度、空分区、管理员 schema 权限。

## Round 1：信息架构与主题

- 假设：删减无关元素、条件渲染分区、下划线 tabs 和语义主题 token 会降低阅读成本且不改变任务能力。
- 实现：默认浅色并用启动前脚本消除主题闪烁；选择写入 `localStorage`；移除品牌、角色摘要、网页筛选和手动刷新；空的运行/队列/历史分区不渲染；主导航改为下划线式页面 tabs。
- 判定：Edge 自动化确认默认浅色、切换深色后刷新仍保持、无冗余控件、空分区隐藏；通过。

## Round 2：管理员进入与 API 文档

- 假设：文件保护的 bootstrap fragment 自动交换比 IP 信任安全，且折叠 OpenAPI 能以较低成本覆盖查阅需求。
- 实现：`localflow open` 用本地权限文件中的一次性 fragment 短码交换 `HttpOnly` 会话，拒绝仅凭回环 IP 提权；OpenAPI 只通过管理员端点提供，网页按 tag 分组并用原生 `details` 渐进披露。
- 判定：匿名 schema 403、无管理员 tabs；失效短码 401 且地址栏清除；有效短码显示 API 页；折叠项具有可见展开指示；通过。

## Round 3：浏览器与目视闭环

- 自动证据：Microsoft Edge 全流程 1/1 通过；axe WCAG A/AA serious/critical 为 0；390px 页面无水平溢出，导航保持单行。
- 目视证据：`../browser/admin-empty-light.png`、`../browser/admin-task-detail-dark.png`、`../browser/admin-api-light.png`、`../browser/admin-mobile-390.png`。
- 删除测试：品牌名、角色徽标、筛选、刷新、空分区和常驻详情说明删除后不损失任务执行、状态识别、配置、终端或 API 查阅能力，因此保持删除；主题开关、状态文字、tab 当前态和详情关闭保留，因为删除会损害关键操作或可理解性。
- 已知预算：Monaco 使主 JS 构建产物约 2.7 MB，Vite 给出 chunk size warning；离线配置编辑能力完整，当前不是功能门禁，后续可把 Monaco 页面动态拆包。

## Round 4：纵向导航、标题删除与设置归位

- 假设：少量一级页面使用左上角纵向 rail，可比横向 tabs 更稳定地扩展“设置”，并让内容区直接开始回答问题；低频主题和校时放入设置页可减少全局噪声。
- 实现：112px 桌面/68px 窄屏纵向导航，图标+文字+左侧选中条；支持上下/Home/End；删除任务、运行、配置和 API 的重复标题；新增设置页，服务器时间自动读取与预填，主题用二选一分段组件。
- 第一轮结果：Edge 功能全过；目视发现设置页 full-page 截图仅按内容高度输出，页面缺少完整视口结构。
- 第二轮修正：设置和运行页增加 `min-height: 100vh`；行为不变，需重签浏览器收据。

## Round 5：自动发现、通俗字段和可运行示例

- 假设：固定目录自动发现会降低运行操作数；插件使用用户标题而非内部名会降低理解成本；一次随机脚本与持续心跳脚本可以覆盖完成、日志、排队与中断的入门路径。
- 实现：`config/tasks` 自动发现，Case 路径输入后自动发现；删除扫描按钮与“磁盘”文案；字段使用 `task`、`inputs`、`case_directory`、`runs`、`seed`、`command`、`mutex_keys`，旧字段仍兼容；初始化与 Release 目录共用 starter 配置和脚本。
- 过程故障：首次大补丁因旧示例字符串转义不匹配被 `apply_patch` 原子拒绝，未产生半修改；拆分所有者后完成。首个 Windows 测试发现 `${root}/scripts` 产生混合分隔符，改为系统生成的 `${scripts_dir}` 后通过。
- 最终证据：初始化/插件 5 项测试通过；一次随机进程正常结束、持续心跳收到 Ctrl+C/CTRL_BREAK 后返回 0；新版 Edge 全流程 1/1 通过并重签收据。加入运行页证据后的首个门禁误用 `toBeVisible` 判断折叠 `<select>` 的 option，候选实际已加载但原生 option 按规范不处于可见绘制状态；检测器改为候选存在且 select 可操作，不放宽自动发现与无扫描控件要求。
- 目视复核：`../browser/admin-run-dark.png` 中插件名使用“普通任务/验证仿真”，高级参数默认折叠；`../browser/admin-settings-light.png` 中主题与时间校准组成两个简洁设置块，服务器当前时间和输入值均已加载。删除测试通过。
