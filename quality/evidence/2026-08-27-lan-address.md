# 局域网启动地址闭环

## 合同

- 新运行根目录默认写入 `bind: 0.0.0.0` 和随机端口。
- 服务仍监听所有 IPv4 网卡，但启动输出和 `runtime/port` 使用默认路由/网卡探测出的首选私有 IPv4，不显示不可复制访问的 `0.0.0.0`。
- 用户可显式配置 `127.0.0.1` 恢复仅服务器本机访问，或配置固定地址/端口。
- 来源 IP 不产生管理员权限；局域网浏览器仍须使用 `secrets/web-admin-key` 登录。
- 可信离线局域网可直接使用 HTTP。存在抓包或中间人风险时必须配置 TLS；只配置证书或私钥之一会拒绝启动，代理 CIDR 配置错误也会拒绝启动。

## 自动判据

- Python 单元测试验证 wildcard 地址投影、直接 HTTP、TLS 配对和代理 CIDR。
- Edge 门禁从新运行根目录启动服务，并使用 `runtime/port` 给出的实际局域网地址完成登录和完整操作旅程。
- Edge 明确验证页面处于局域网 HTTP 的非安全上下文，并验证现代 Clipboard API 不可用时仍能准确复制，而不是依赖 `localhost` 特例。
- Linux Release 门禁从最终二进制初始化运行目录并执行任务闭环；下载后的发布物再次执行同一 smoke。
