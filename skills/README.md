# LocalFlow Agent Skills

Each subdirectory is an independent skill for AI agents working with an extracted LocalFlow package.

| Skill | Use |
| --- | --- |
| `localflow-project` | Project structure, owners, and change boundaries |
| `localflow-api` | Signed program API and task control |
| `localflow-configuration` | Configuration files, imports, diagnosis, and runs |
| `localflow-plugin-development` | Plugin schemas, hooks, statuses, and examples |
| `localflow-operations` | Ubuntu deployment, restart, retention, and cleanup |

Load only the skill matching the current task. Detailed product contracts remain in `docs/` and are linked from each skill.
